# ☕ Hub Café

Site de uma cafeteria de bairro, feito no curso **Web do Zero**. O visitante vê o cardápio, monta um pedido e informa o endereço de entrega.

# O que faz

- Mostra saudação e avisa se a loja está aberta ou fechada, conforme o horário.
- Exibe a temperatura atual e sugere uma bebida.
- Cardápio com busca por nome e filtros por categoria.
- Pedido com total automático, salvo no navegador.
- Preenche o endereço automaticamente pelo CEP.
- Modo escuro e menu responsivo para celular.

# Tecnologias

- HTML5, CSS3 e JavaScript
- APIs: Open-Meteo (clima), ViaCEP (endereço) e OpenStreetMap (mapa)
- Google Fonts: Poppins
